# Nether

Permanently capitalized monetary protocol on Base. Users bury ETH in the Grave and receive NETH. Yield funds the Reaper, which buys and burns NETH.

Spec: [`docs/protocol_spec.md`](docs/protocol_spec.md). Plans: [`docs/nip/`](docs/nip/README.md). Site: [rastsislaux.github.io/nether](https://rastsislaux.github.io/nether/). License: source-available until Base mainnet, then MIT ([`LICENSE.md`](LICENSE.md), [`NDR-0004`](docs/ndr/0004-source-available-until-mainnet.md)).
